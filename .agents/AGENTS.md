# Reglas del Proyecto (AGENTS.md)

- **Obligatoriedad de Plan de Implementación**: Para todo cambio, modificación o nueva funcionalidad en la aplicación (frontend o backend), el agente DEBE generar primero un plan de implementación (`implementation_plan.md`) con la propuesta técnica detallada, preguntas abiertas y plan de verificación, y esperar la aprobación explícita del usuario antes de proceder con la ejecución del código.
